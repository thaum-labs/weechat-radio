How to set the levels

TX level only turns down: the modem already sends at full scale. Set the deviation with the radio's own mic gain (the Bluetooth mic gain on a VR-N76, the Digirig's Speaker in alsamixer), then lower TX level a step at a time until the far end's SNR stops getting better.
