v1.0.20-rc14 is a release candidate. Get it with `wcr update --rc`. It carries everything from rc13 back to rc6.

## Pi mail takes big files again

The Pi mail form stayed on 8 KB even on vhf-fast: the Pi page never got the station's file limit and used its own built-in 8 KB.

- The Pi page now gets the limit from the station and rechecks attached files when the preset changes.
- A station in Internet or Internet+Radio mode (a gateway) sends its own mail to the hub over the internet, so it takes files up to 512 KB on any preset.
- Radio+ takes files up to 512 KB on vhf-fast, and no files on other presets. The form says so instead of "8 KB".

## Several attachments

- Desktop and Pi mail take several files, up to 512 KB in all. "Attach files" picks one or more; "Attach more" adds to the list; each file has its own remove button.
- The recipient gets every file as an email attachment. Mail read on the desktop or Pi lists every file.

## Resends after lost reports

rc13's first 32 KB mail resent chunk 1 twice and then sent the last 7 chunks slowly. The gateway's "have" reports went out on QAM16 and the handheld missed two of them; each miss counted as a retry, and the third try on vhf-fast drops to RDM-1200S, where a 1 KB chunk takes about 15 s.

- Gateway reports and acceptances now go on QPSK on vhf-fast, so they carry further.
- A report that shows progress puts the sender back on the first rung.

## Clearer forms

- Pi mail form: one message at a time. A refused file gets one orange line saying why; the grey limit line hides while it shows.
- The Send hint lists everything still missing, for example "To send: remove qa-32k.bin, add an email address in To and add a subject."
- Pi chat file refusal names the preset and says vhf-fast allows bigger files.
