v1.0.18-rc3 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.18-rc2

**Find radio on Linux and Raspberry Pi (#331)**
- **Find radio** (desktop app), `wcr tnc find` and the radio step of `wcr setup` now work on Linux, including a Raspberry Pi over SSH, for the VR-N76, VR-N7600, UV-PRO and GA-5WB. A radio that is already paired is picked straight away. Otherwise it searches for about 8 s, pairs (it answers PIN 0000 and yes/no prompts) and trusts the radio, so it reconnects by itself.
- It uses BlueZ's `bluetoothctl`, which Raspberry Pi OS already has. When something blocks it, the message names the fix: install bluez, `sudo rfkill unblock bluetooth`, add your user to the `bluetooth` group, or start the Bluetooth service. With no Bluetooth adapter it gives up after 10 s instead of waiting forever.
- Raspberry Pi 3: Bluetooth shares its antenna with 2.4 GHz Wi-Fi, so use Ethernet if you can and keep the radio within a few metres.
