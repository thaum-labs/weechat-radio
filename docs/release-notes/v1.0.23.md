v1.0.23 is a small desktop tidy-up after v1.0.22. Run `wcr update` to get it.

## What changed since v1.0.22

- STATION panel: the MODE, FREQ and PRESET pickers and the BT FAST button no longer run off the right edge and get cropped on a narrow window.
- BT FAST: the button now reads `on (experimental)` / `off`. The Bluetooth (SBC) warning moved into its hover tip, so there is no longer a block of orange text under the row. The preset picker still tags `vhf-fast (experimental)`.

Only the desktop app changed. Nothing on the air changed, so v1.0.23 talks to v1.0.22 and earlier exactly as before.
