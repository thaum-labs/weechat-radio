v1.0.17-rc3 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.17-rc2

**File transfers: progress bars, Desktop saving, clickable path (#312)**
- Both sides show a DOS-style progress bar, such as `[█████████░░░░░░░░░░░] 9/15`, in the desktop app and on the Pi web page.
- Sender: the bar on the file line moves with each piece receipt. `[ok]` still means the other station has the whole file.
- Receiver: a "📎 receiving a file from CALL" line appears on the first piece, and its bar fills as pieces arrive.
- Received files are saved in a `WeeChat Radio/CALL` folder on the Desktop (Mac, Windows, Linux with a desktop). A machine with no Desktop (such as a headless Pi) saves them in `files/CALL` beside the station's data. `[store] files_dir` in wcr.toml picks another folder.
- The saved path is a link. In the desktop app it opens the folder (never the file itself). On the Pi web page it downloads the file.

**Radio+ Auto mail gateway (#313)**
- MAIL GW turns green as soon as a gateway acks your mail or answers Check mail.
- After "No mail gateway heard", the station asks again by itself (after 2 min, then less often up to hourly, and once sooner when it hears a gateway beacon) instead of waiting for a restart.

**Desktop app and Pi web page polish (#311)**
- Desktop app: grey box hints, aligned station panel, [net] in the stations list, clearer On air, Email and Help wording.
- Pi web page: tabs stay on one row on phones, filled Send and Log in buttons, matched Open button height.

Everything in v1.0.17-rc2 (small files in direct messages, Pi leave group / delete chat) is included.
