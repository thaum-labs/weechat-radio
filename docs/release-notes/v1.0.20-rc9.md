v1.0.20-rc9 is a release candidate. Get it with `wcr update --rc`. It carries everything from rc8, rc7 and rc6.

## Pictures in direct chats, on vhf-fast

- Attach a picture (JPG, PNG, GIF, WebP or BMP) with `/file`, by dragging it onto the desktop app, with the files button, or with File on the Pi page. If it is bigger than 8 KB, the station shrinks it for you: it makes it smaller and saves it again as JPEG until it fits. No more hunting for a small picture.
- 8 KB is about 300×200 pixels and takes about 2 minutes to send on `vhf-fast`.
- Pictures go on `vhf-fast` only. Other small files are unchanged: up to 4 KB on `vhf-fm`, `vhf-fast` or `afsk-1200`.
- The shrunk JPEG carries no metadata, so a phone photo's location does not go on the air.
- The Pi page shrinks in the browser, so a phone's own photo formats (HEIC on an iPhone) work there.
- The station that receives needs rc9 too: older stations refuse anything over 4 KB, and the sender's file line ends at [no].
- The time shown for a file now counts real modem73 frames, so it is honest: a 4 KB file takes about 1 minute on `vhf-fast` and 1.5 minutes on `vhf-fm` (it used to say 30 s).

## What to test

1. On `vhf-fast`, between two rc9 stations, attach a phone photo of a few MB in a direct chat. The note should say it was shrunk, the file line should show about 8 KB and about 2 minutes, and the far end should save a .jpg that opens the right way up.
2. Do the same from the Pi page on a phone.
3. On `vhf-fm`, attach a picture: it should be refused with "pictures go on vhf-fast only". A small text file should still send as before.
