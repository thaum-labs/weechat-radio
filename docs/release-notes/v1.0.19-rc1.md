v1.0.19-rc1 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.18

**modem73 moves to v2.5.0 (#357)**

This RC changes nothing else, so anything new on the air is down to modem73.

- The bundled modem73 is now **2.5.0-wcr** on Linux, Raspberry Pi, macOS and Windows (it was 2.4.8-wcr, and 2.4.2-wcr on Windows). `wcr update --rc` moves it with the app; no manual steps.
- Network audio for the VR-N76 / VR-N7600 Bluetooth path (`-d tcp:HOST:PORT`) is now built into modem73 upstream, so our own patch for it is gone. Same wire format: wcr's Bluetooth bridge is unchanged.
- Still patched in by us: the level meter readings and the waterfall (Linux, Pi, macOS), TX level down to 1 %, the CSMA sync slot fix from #241 (all platforms), and encoding a frame before the busy test so PTT keys straight after "Channel clear" (Linux, Pi, macOS).
- The radio signal itself is unchanged between 2.4.8 and 2.5.0, so a station on this RC and one on v1.0.18 still hear each other.
- One upstream change to watch: with VOX PTT, modem73 now sends one frame per keying instead of up to two back to back.
