v1.0.18-rc6 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.18-rc5

**Desktop app: an optional modem73-style layout (#345)**
- A second look for the desktop window, in the style of modem73's own screen: a one-line header (RX or TX, call, mode, frequency, clock), tabs for Live chat, Email, On air and Setup, a strip with STATION, SIGNAL and ACTIVITY, and a footer of keys.
- ACTIVITY draws the last 6 seconds of receive level as bars, like modem73's graph, and goes red while you transmit.
- The classic layout stays the default. To try the new one, add `layout = "modem73"` under `[ui]` in wcr.toml, or start it once with `wcr-gui --ui-layout modem73` (or `WCR_UI_LAYOUT=modem73`).
- Every button works as before. In the new layout F1 opens help, F2 the mark key, and Tab, S, M, W and Q switch tab, stop, open the map, WeeChat and quit while no text box is selected.
