v1.0.16-rc10 is a release candidate. Get it with `wcr update --rc`. On rc3 to rc9, press Update on the web page or in the desktop app.

Same code as v1.0.16-rc9 plus one desktop app layout fix.

## What changed since v1.0.16-rc9

**Desktop app: IN advice moves into IN's hover tip**
- The level advice under the IN meter ("good", "loud hiss, normal at squelch 0" and so on) changed length as the audio changed, which pushed the level knobs and the rows below up and down.
- IN is now always one line tall. The advice appears when you hover over IN, after the level explanation. The IN number's colour still shows good, quiet or loud at a glance.

Nothing else changed.
