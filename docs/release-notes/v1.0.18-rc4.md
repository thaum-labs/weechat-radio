v1.0.18-rc4 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.18-rc3

**Set the dial frequency from the Pi web page (#334)**
- The Station card on a Pi's web page has a **Dial frequency** box under **Dial, mode and preset**. Type the MHz (e.g. 144.950) or pick a calling spot, then Save. It does what `/radio freq` does in the desktop app: the running station uses the new dial at once (station panel, beacons, map), with no restart, and it is saved as `frequency_khz` in wcr.toml, so it is kept across restarts. It can be set while the station is stopped too.
- wcr never retunes the radio. The page says so: turn the radio's own dial to the same frequency.
- With CAT on, the page shows the radio's own reading, which wins.
- The page warns about 144.800 and 144.390 (APRS), PMR446 (licence-free handhelds only) and frequencies outside any known band.
- The Station card now always lists the dial, even while the radio is not ready.
