v1.0.18-rc7 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.18-rc6

**/report and /rangetest are refused when incomplete (#347)**
- In the desktop app, `/report` with no station (outside a private tab), `/report` with something that is not a callsign, `/report auto` without on or off, and `/rangetest` with a bad callsign or a bad number of seconds are not sent. The usage line shows instead.
- Picking `/report` or `/rangetest` from the command list now waits for you to type the callsign instead of sending at once. `/report` alone in a private tab still asks that station.
- The station checks the same things, so the terminal app and WeeChat `/radio` get them too.

**Range test: at least 30 s between probes (#347)**
- `/rangetest CALL 20` is refused with "20 s is too short: a range test needs at least 30 s between probes". The gap is 30-600 s; the default stays 30 s. A Pi at the far end could not keep up with 20 s probes.
