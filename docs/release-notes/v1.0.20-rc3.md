v1.0.20-rc3 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.20-rc2 (QA #365)

**Changing the preset applies by itself**

- Saving a new preset (setup, the PRESET drop-down, `/radio preset`, or editing wcr.toml) now restarts modem73 on its own once the radio is idle (nothing keyed, nothing queued for 2 s; at most 2 minutes wait). Chat says "modem73 restarted: X -> Y".
- Until then the app says "restart to apply" next to PRESET, and `/status` shows the mode modem73 is actually running, for example `vhf-fm (restart to apply: modem73 still runs vox-safe)`.

**Long messages show as one entry (agreed design on #365)**

- A message longer than one frame is sent in pieces that start with `[1/3] `, `[2/3] `, … (Tobias chose this "option B"). The tag counts toward the 300-byte frame limit.
- Receiving: one entry that fills in as pieces arrive, with "⋯ more coming · n/N received" in amber, then "✓ complete · N/N" in green. Other stations' lines print below it, never inside it. If a piece is still missing 5 minutes after the last one, it turns red: "⚠ incomplete · n/N received · part X missing".
- Sending: one entry with "sending 2/3 ■■□" and one delivery tick for the whole message.
- Same in the desktop app (both layouts), the terminal UI, the web page and WeeChat. Older versions show the `[1/3]` tags as text, which is fine.
- If you type `[1/2] ` at the start of a line yourself, it is escaped so it never groups by accident.

**Emoji**

- Long lines are never cut inside an emoji (or a skin tone or family emoji), so nothing arrives as a broken character. Tested over the simulated air link and the hub.
- The desktop app draws emoji it has no glyph for as a readable placeholder instead of an empty box. Terminal and web keep full colour emoji where the font has them.

**Callsign colours**

- Other stations' callsigns are cyan in the chat (all views) and in the desktop status bar ("DIRECT · M7TJF only").

**VOX guide (PR #368 folded in)**

- The VOX guide and RADIO-SETUP.md list squelch 1 / VOX 4 for the VR-N76 and RT-900, keeping the PC level low (Windows Volume mixer about 20 to 25), tuning by SNR, and vhf-fm vs vox-safe. `wcr setup` VOX help says the same, plus: if the radio keys by itself, lower the power, add ferrites, or try another cable.

Everything else is as in rc2 (MAIL GW key #362, Windows live IN meter #364).
