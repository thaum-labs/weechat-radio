v1.0.18 is the final release of the v1.0.18 series: everything from v1.0.18-rc1 to rc9, with no changes since rc9. Run `wcr update` to get it. On an RC, press Update on the web page or in the desktop app.

## What changed since v1.0.17 (rc1 to rc9)

**Range test mode and coverage map (#325, rc1; #342, rc5; #347, rc7)**
- `/rangetest CALL` sends CALL a short private probe every 30 s (`/rangetest CALL 60` picks another gap, 30 to 600 s). Each probe is logged with your GPS position as `both`, `heard_them` or `none`, plus the SNR at both ends, to a CSV and KML file. `/rangetest off` stops it and cancels a probe still waiting to be sent.
- A receipt that comes back up to 3 minutes late still counts as "both ways", and probes no longer pile up in the send queue on a busy channel.
- Website page https://weechatradio.com/guides/range.html: drop CSV files on it to see the coverage area on a map, with a replay button.

**GPS satellites and traffic light (#329, rc2)**
- The GPS line shows satellites seen while waiting for a fix, and satellites used once it has one. A dot shows red (nothing), amber (satellites, no fix) or green (fix).

**Find radio on Linux and Raspberry Pi (#331, rc3)**
- **Find radio**, `wcr tnc find` and `wcr setup` now find and pair the VR-N76, VR-N7600, UV-PRO and GA-5WB on Linux and a Pi through `bluetoothctl`.

**Set the dial frequency from the Pi web page (#334, rc4)**
- The Station card has a **Dial frequency** box. The running station uses it at once and it is saved in wcr.toml. wcr never retunes the radio; turn its own dial to match.

**/report and /rangetest are refused when incomplete (#347, rc7)**
- A missing or bad callsign, or a bad number of seconds, shows the usage line instead of sending. Picking them from the command list waits for the callsign.

**Desktop app: modem73-style layout is the default (#345 rc6, #350 rc8, #352 rc9)**
- One-line header, tabs for Live chat, Email, On air and Setup, a STATION / SIGNAL / ACTIVITY strip with level bars, and a footer of keys. TX LVL and RX GAIN bars can be clicked or dragged; Q asks before quitting.
- For the old window, put `layout = "classic"` under `[ui]` in wcr.toml, or run `wcr-gui --ui-layout classic`.

modem73 stays on the same builds as rc9 (v2.4.8-wcr, Windows v2.4.2-wcr).
