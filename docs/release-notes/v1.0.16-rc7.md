v1.0.16-rc7 is a release candidate. Get it with `wcr update --rc`. On rc3 to rc6, press Update on the web page or in the desktop app.

Same code as v1.0.16-rc6 plus one fix for Bluetooth radios.

## What changed since v1.0.16-rc6

**Bluetooth radios: IN and OUT meters show the radio's audio**
- For radios on Bluetooth audio (VR-N76, VR-N7600, `[modem] ptt = "bluetooth"`), wcr now measures the audio it passes between the radio and modem73 itself:
  - **IN** is the radio's received audio as modem73 hears it (after the RX gain). It moves on any sound from the radio (a whistle, a voice, hiss at squelch 0), not only when a frame decodes. When the radio sends nothing at all, IN shows a dash, the same as modem73's own meter.
  - **OUT** is the audio sent to the radio while PTT is held (after the TX level), and empty otherwise.
- Before, Windows metered the PC's default speakers for OUT (music showed there) and moved IN only on a decoded frame; macOS and Linux could meter the PC's default microphone for IN. Those sound-card meters are no longer started on Bluetooth.
- The level words and RX gain hints now work on Windows Bluetooth stations too, since IN is a live level there.
- Sound-card and VOX stations are unchanged. The frozen Live Chat RF code and modem73 are untouched.
