v1.0.17-rc2 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.17-rc1

**Small files in direct messages, VHF/UHF only (#308)**
- `/file CALL path` (or `/file path` in a direct chat) sends a file of up to 4 KB to one station.
- Direct messages only, never channels; only on `vhf-fm` or `afsk-1200`; only over the radio, never through the hub. Other presets and channels refuse with the reason.
- 4 KB takes about 30 s on `vhf-fm` and about 1.5 min on `afsk-1200`. The file line shows the estimate.
- The file goes out in pieces; each piece gets a receipt and is sent again if lost. **[ok] on the file line means the other station has the whole file**: it answers the last piece only once every piece is saved.
- Received files are saved in `files/CALL` beside the station's data.
- Desktop app: drag a file onto the window while a direct chat is open; the new **files** button opens the received files folder.
- Pi web page: **File** button in a direct chat.
- Files are sent as they are, never encrypted. A station on an older version cannot receive them (the sender's line ends at [no]).

Everything in v1.0.17-rc1 (direct message notifications and chats, /report on Enter) is included.
