v1.0.20-rc4 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.20-rc3 (QA #365)

**Desktop chat input grows as you type**

- The input starts at one line and grows with the text up to 5 lines, then scrolls inside the box. Pasted text wraps, and the chat log above shrinks to make room.
- Enter sends. Shift+Enter starts a new line (it goes as a space, since a chat line is one line on air).

**Progress and receipts on the message's own line**

- Desktop app (both layouts): `sending 1/2 ■□ … awaiting receipt`, `✓✓ delivered`, `⋯ more coming`, `✓ complete · 3/3` and `⚠ incomplete` now sit on the same line as `[tx] [x1]`, `[ok]`, `[rf] 13 dB`, right-aligned in the modem73 layout.
- Pi web app: the same text sits just after the `[rf] 10 dB` / `[tx]` marks on the same row, same colours, and wraps as one piece on a phone.
- Terminal UI: the same, at the end of the line.

**Preset changes apply by themselves, everywhere**

- Changing the preset (desktop drop-down or setup page, Pi web app, TUI `/preset`, or a wcr.toml edit) says "restarting modem…", then "now running <preset>" once the radio is idle.
- This now also works when the station found modem73 already running instead of starting it (that case used to keep the old mode silently): the new preset goes to modem73 over its control port.
- `/status` and the apps show the preset modem73 is really running, for example `vox-safe (restarting modem for vhf-fm…)` while it moves.
- "Stop and start to apply" only shows when the automatic restart fails, with the reason.

**Emoji in the desktop app as names**

- The desktop app shows every emoji as its name, both received and typed or pasted: 🙂 is `:slightly_smiling_face:`, 😊 is `:blush:`, 👍🏽 is `:+1::skin-tone-4:`. The font is unchanged.
- What goes on air and into the database is still the real emoji: names typed or shown in the box turn back into emoji when you send.
- The Pi web app is unchanged and keeps showing real emoji.

**Select and copy chat text (desktop)**

- Drag over chat text to select it and press Ctrl+C (Cmd+C on a Mac). The mouse wheel and the scroll bar still scroll.

Everything else is as in rc3 (`[1/3]` grouping, emoji-safe splits, cyan callsigns).
