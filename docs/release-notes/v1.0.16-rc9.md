v1.0.16-rc9 is a release candidate. Get it with `wcr update --rc`. On rc3 to rc8, press Update on the web page or in the desktop app.

Same code as v1.0.16-rc8 plus one Pi web page fix.

## What changed since v1.0.16-rc8

**Pi web page: Gateway mode and Mail gateway choices readable**
- The page's text box style also applied to the round radio buttons, so each button was drawn full width and pushed its label on top of the next one ("Chat and mail" over "Mail only", Save on top). Worst in Safari.
- Radio buttons and checkboxes now keep their own size, and the choices in the Gateway mode and Mail gateway rows no longer shrink into each other.

Nothing else changed.
