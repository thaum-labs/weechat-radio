v1.0.17 is the final release of the v1.0.17 series: everything from v1.0.17-rc1 to rc3, plus the email progress bars and clickable new-mail alert (#316). Run `wcr update` to get it. On rc3 or later, press Update on the web page or in the desktop app.

## What changed since v1.0.16 (rc1 to rc4)

**Email: DOS-style progress bars and a clickable new-mail alert (#316)**
- Desktop app: the Sending email and Getting email windows show a text bar, such as `[████████░░░░░░░░░░░░]  40%`, the same look as file transfers.
- Pi web page: a Radio+ Get shows a bar above the inbox while chunks arrive; outbox mail on the air shows a bar of the chunks the gateway has, such as `4/6`.
- Desktop app: when mail arrives, an alert at the top right says "New mail from X: subject" with Open. Click it to go straight to that email. It goes away once the mail is read, or with x. The system notification names the sender and subject.
- The Get window has Open once the mail is fetched; so does the Pi page's "Fetched" line.

**File transfers: progress bars, Desktop saving, clickable path (#312, rc3)**
- Both sides show a progress bar, such as `[█████████░░░░░░░░░░░] 9/15`, in the desktop app and on the Pi web page.
- Received files are saved in a `WeeChat Radio/CALL` folder on the Desktop; a machine with no Desktop (such as a headless Pi) saves them in `files/CALL` beside the station's data. `[store] files_dir` picks another folder.
- The saved path is a link: the desktop app opens its folder, the Pi page downloads the file.

**Small files in direct messages, VHF/UHF only (#308, rc2)**
- `/file CALL path` (or `/file path` in a direct chat) sends a file of up to 4 KB to one station, only on `vhf-fm` or `afsk-1200`, only over the radio. `[ok]` on the file line means the other station has the whole file.
- Desktop app: drag a file onto the window in a direct chat; **files** opens the received files folder. Pi web page: **File** button in a direct chat.

**Desktop app: direct messages notify you and get their own chats (#303, rc1)**
- A direct message opens a direct chat with its sender (it used to land in a hidden channel). New **direct** row with "N new" counts; system notifications for each incoming direct message.

**/report sends on Enter (#304, rc1)**
- Picking `/report` sends straight away. In a direct chat, a bare `/report` asks that station for a signal report.

**Radio+ Auto mail gateway (#313, rc3)**
- MAIL GW turns green as soon as a gateway acks your mail or answers Check mail. After "No mail gateway heard", the station asks again by itself.

**Pi web app (#307, rc2) and polish (#311, rc3)**
- **Leave group** and **Delete chat** on the open conversation. Tidier desktop app and Pi page.
