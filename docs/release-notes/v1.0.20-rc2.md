v1.0.20-rc2 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.20-rc1

**MAIL GW key moved (#362, Tobias on rc1)**

- The key no longer sits beside the ACTIVITY graph, where it took the graph's width. It is now in the bottom-right corner of the ACTIVITY panel, next to STATS, and the graph uses the full width again.
- It only shows when STATS leaves room beside it (from about 1200 px wide). On a narrower window it hides instead of covering anything; hover the MAIL GW dots for the states. Wide windows (about 1600 px) also show the short meanings.
- Still Radio+ with a mail gateway set only.

**STATION and SIGNAL use their empty space (Tobias on rc1)**

- STATION: a HEARD list under PTT / MODEM, the stations heard most recently with band, last SNR and how long ago. As many rows as fit.
- SIGNAL: an SNR LOG under RETRY / AIR / HOLD, one bar per frame heard, newest on the right. Green 10 dB and up, gold 3 to 10, red below 3. Hover for the last value and the range. The app now reads the station's frame log every 2 s in this layout (before, only while ON AIR was open).

Everything else is as in rc1 (Windows live IN meter #364, VOX setup help #365).
