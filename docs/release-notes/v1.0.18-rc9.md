## What changed since v1.0.18-rc8

**modem73 layout: STATION and SIGNAL tidy-up (#352)**
- STATION is one column. MODE, FREQ and PRESET are as wide as the panel, so "144.950 2m FM UK/EU" and "modem73 v2.4.2-win" show in full. CALL and GRID share the top row.
- STATION labels sit in the same column as SIGNAL's, and the values line up with the text inside the pickers.
- The FREQ picker text is left-aligned like MODE and PRESET (classic too).
- SIGNAL readings are right-aligned, so the bars end with the same padding on the right as on the left. IN shows good, low or hot; the hover tip has the detail.
