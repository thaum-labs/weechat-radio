v1.0.16-rc4 is a release candidate. Get it with `wcr update --rc`. On rc3, press Update on the web page or in the desktop app.

## What changed since v1.0.16-rc3

**The Pi starts at boot with no extra commands (#280)**
- On a Pi (Linux with no desktop), the end of `wcr setup` now finishes the install:
  - it asks for the web page password;
  - then it asks "Start the station now and at every boot?". On yes it runs `sudo wcr web install` itself, and sudo asks for your password once.
- Each question appears only if that step is not done yet. A working gateway, with a password set and the `wcr-web` service in place, is asked neither, so nothing changes on a live station.
- On a Pi, setup no longer offers the per-user background service (`wcr service install`). That service would compete with `wcr-web` for the radio.
- The Pi guide (website and docs/PI-GATEWAY.md) is now: install, add the serial/audio groups, `wcr setup`, open the page.

**Testing the update from rc3**
rc4 is the release QA updates to from rc3. It is used for:
- the Update button on the web page and in the desktop app;
- `wcr update --test-rollback`, which installs rc4 as a deliberately bad build and must bring rc3 back.
