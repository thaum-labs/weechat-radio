v1.0.16-rc2 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.16-rc1

**Hub accepts Radio+ gateway asks and Check mail again (#278)**
- The hub refused a Radio+ station's signed mail gateway ask (401 "gateway ask") and its Check mail through a gateway (401 "mail pull") when it already had a different key on file for that callsign, for example after a new install or a new data folder. A Radio+ station only reaches the hub through a gateway, so it had no way to update that key, and Auto showed "No mail gateway heard".
- The hub now takes the station's new key from a correctly signed ask or pull, the same rule it already uses when a station logs in or sends a telemetry report: the new key replaces the old one unless a station with that callsign is on the hub at that moment.
- A wrong signature, a request signed for another callsign or other messages, or a clock more than 10 minutes out is still refused, and the 401 now says which ("gateway ask: bad signature", "mail pull: callsign in use by another key", ...), so the gateway's log shows the reason.
- Portable callsigns such as M7TJF/M are covered by new tests that go through the real hub handlers and key table.
- The fix is in the hub, which updates when this is merged. The station code only moved the signing into shared functions the tests use; nothing changes on the air.
