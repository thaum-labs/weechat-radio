v1.0.20-rc10 is a release candidate. Get it with `wcr update --rc`. It carries everything from rc9, rc8, rc7 and rc6.

## Files with email

- **Sending:** one file can go with a mail, any type (CSV, TXT, PDF, a picture...). Pictures are shrunk to fit 8 KB, the same as in chat; other files go as they are, up to 8 KB. In the desktop app, drag the file onto the window while the Email screen is open (it shows "📎 name (size)" with remove). On the Pi page, press Attach file under the message.
- The person you write to gets a normal email with the file attached.
- Over the radio, files go with mail on `vhf-fast` only. Mail sent over the internet (Internet or Internet+Radio modes) can always carry one.
- Any gateway carries it: the file rides inside the mail text, so gateways need no update. It costs about a third more airtime: an 8 KB file is about 1.5 minutes on `vhf-fast`.
- **Receiving:** when someone emails you a file, the hub keeps the first one that can go over the radio (pictures shrunk to 8 KB, other files up to 8 KB). Bigger files are named in the mail as "Not sent over the radio: name (size)". Logos inside the email are left out.
- When you open that mail, the file is saved in the received files folder (under `mail`) and the mail shows "📎 name (size)": in the desktop app with "open folder", on the Pi page as a download link.
- A station on an older version shows the file as a block of letters at the end of the mail.

## What to test

1. On `vhf-fast` in Radio+, write a mail to your own email address with a CSV attached. It should arrive as a normal email with the CSV attached and the text without any block of letters.
2. Do the same with a phone photo from the Pi page: the note says it was shrunk, and the email has the .jpg attached.
3. On `vhf-fm` in Radio+, attaching should be refused with "Files go with mail over the radio on vhf-fast only".
4. Email the station's address from your phone with a photo and a big PDF. Check mail and Get it: the mail should say "Not sent over the radio: <the PDF>", show "📎 <photo>.jpg", and the photo should open from the folder or download link.
