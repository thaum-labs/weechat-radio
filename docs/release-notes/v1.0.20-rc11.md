v1.0.20-rc11 is a release candidate. Get it with `wcr update --rc`. It carries everything from rc10 back to rc6.

## Chat files in one burst (vhf-fast)

- On `vhf-fast` a file now goes in one burst: every piece is keyed back to back. The other station answers once, saying which pieces it missed, and only those go again. An 8 KB picture takes about 45 seconds instead of several minutes.
- New setting **File send**: auto (burst on vhf-fast, piece by piece elsewhere), burst or pieces. Desktop: FILES row. Pi page: Station section. Chat: `/filesend auto|burst|pieces`. Or `[rf] file_send` in wcr.toml.
- The file line steps frame by frame while sending and piece by piece while receiving.
- A station on rc10 or older still receives the file; it answers each piece as before.

## Bigger files with email (vhf-fast)

- A mail can carry a file up to 512 KB on `vhf-fast` (8 KB on other presets). It goes in blocks of about 2 minutes; 512 KB takes about half an hour.
- The send window shows chunk-by-chunk progress and has a **Cancel** button (desktop and Pi page). The gateway shows the mail coming in.
- The gateway must run this version for files over 8 KB.
- Files emailed to you still come over the radio up to 8 KB.

## Fixes

- A file that can't go with a mail now shows "Not attached" and blocks Send until you remove it. Before, the mail went without the file.
- Pi page: attaching a picture over 8 KB works again (the page's security policy blocked it).
- Gentler wording for vhf-fast over VOX (still refused over Bluetooth).
- Solid progress bars on the Pi page, "Restarting modem…" turns into "Now running …", and the desktop "Sending email" bar fills the window.

## What to test

2. Repeat with the far radio briefly off mid-burst: only the missing pieces go again.
3. Send a picture from rc11 to a station on rc10: it still arrives.
4. Send a 32 KB and a 128 KB file by mail through an rc11 gateway, and Cancel one halfway.
5. On the Pi page, attach a phone photo to a mail and to a chat.
