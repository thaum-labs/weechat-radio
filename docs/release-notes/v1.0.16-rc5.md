v1.0.16-rc5 is a release candidate. Get it with `wcr update --rc`. On rc3 or rc4, press Update on the web page or in the desktop app.

## What changed since v1.0.16-rc4 (QA #284)

**A restart you ask for no longer undoes an update**
- `wcr restart`, Restart to finish, Start/Stop or another Update within 60 s of an update used to count as a failed start, and the update was rolled back ("it stopped 2 times while starting"). A restart the operator asks for now confirms the new version first. A build that really fails to start, or `wcr update --test-rollback`, still rolls back.

**`wcr setup` run again keeps the saved settings**
- Every Enter keeps what the file says: callsign, grid, the radio, its port, the preset, the hub and map choices. The grid guessed from your internet address is only shown next to the saved one; it is the default only when no grid is saved.
- Everything setup does not ask about stays exactly as it was: TX level, RX gain, busy test, mail, the web page. Picking a different radio than before starts the modem settings fresh (a TX level tuned for one radio is wrong for another).

**Desktop app: RX GAIN and TX LVL with a VR-N76 on Bluetooth audio**
- The sliders were hidden because the app took the Bluetooth link ("VR-N76 linked") for the radio's built-in TNC. They now show whenever modem73 is the modem, like the web page.

**Bluetooth audio setup saves no sound card**
- The sound goes over wcr's own Bluetooth link to the radio, so the Mac's microphone and speaker are never used. Setup (desktop and terminal) now clears the sound device fields and says so, instead of keeping "Built-in Microphone".

**Setup pages save themselves**
- Desktop app: moving off the setup page (live chat, email, on air, Back) saves it. If the station is running and something changed, a line says to stop and start it.
- Pi web page: the mail gateway saves as soon as you pick Auto or finish typing a callsign.

**Cosmetic**
- The Software card and window say "Running 1.0.16-rc5".
