v1.0.18-rc8 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.18-rc7

**modem73 is the default desktop layout (#350)**
- The desktop app opens in the modem73-style layout. For the old window, put `layout = "classic"` under `[ui]` in wcr.toml, or run `wcr-gui --ui-layout classic`.
- A wcr.toml that rc6 or rc7 already saved with `layout = "classic"` stays classic.

**modem73 layout polish (#350)**
- SIGNAL: the IN, OUT and OCC bars fill the column and resize with the window.
- TX LVL and RX GAIN show a bar: click or drag on it to set the level, scroll to nudge, double-click for 0 dB.
- ACTIVITY: the graph fills the panel, no empty band at the bottom.
- Q (or "Q quit" in the footer) asks "Are you sure you want to quit?" in a centred box. Enter quits, Esc cancels.
- Setup opens "Other setups" by default.
- The `///` logo is weechat-radio's blue, orange and purple instead of modem73's purple.
- Email: a little space between the message box and the Send row (classic too).
