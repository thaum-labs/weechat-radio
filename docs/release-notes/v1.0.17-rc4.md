v1.0.17-rc4 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.17-rc3

**Email: DOS-style progress bars (#316)**
- Desktop app: the Sending email and Getting email windows show a text bar, such as `[████████░░░░░░░░░░░░]  40%`, the same look as file transfers.
- Pi web page: a Radio+ Get shows a bar above the inbox while chunks arrive. Outbox mail on the air shows a bar of the chunks the gateway has, such as `4/6`.

**Email: clickable new-mail alert (#316)**
- Desktop app: when mail arrives, an alert at the top right says "New mail from X: subject" with Open. Click it to go straight to that email. It goes away once the mail is read, or with x.
- The system notification names the sender and subject.
- The Get window has Open once the mail is fetched. On the Pi web page the "Fetched" line has Open too.

Everything in v1.0.17-rc3 (file progress bars, Desktop saving, Auto gateway re-ask, UI polish) is included.
