Same code as v1.0.16-rc7 plus the station panel changes below.

## What changed since v1.0.16-rc7

**Desktop app station panel**
- **Level knobs:** RX GAIN and TX LVL are two radio-style knobs side by side under the meters, with the value in the middle of the dial. Drag up or right to turn up, scroll to step, double-click for 0 dB. Hover for the help text.
- **MAIL GW bar:** the mail gateway line is now a three-segment bar the length of the IN/OUT meters. Grey: not asked yet. One purple segment: asking. All green: a gateway is ready (Auto's pick or one typed in setup). All orange: no gateway. Hover it for the callsign and link.
- **Help folded away:** the keys and commands list is one line ("HELP · keys and commands") at the bottom of the left column. Click it and the list takes the whole left column; click the header again to get the station back.

**Bluetooth radios: level advice**
- On FM at squelch 0 the open-squelch hiss reads near full scale, louder than the messages, and the radio's volume knob does not change its Bluetooth audio (VR-N76, tested by Tobias). Loud or clipping idle input on Bluetooth now reads "good" with a note that nothing needs changing. The only advice left is "lower RX gain to 0 dB" when RX gain is above 0 dB.
- RX gain help on the desktop app and web page says the same.

**Web page**
- TX level shows one decimal like RX gain.

Sound-card stations, the frozen Live Chat RF code and modem73 are unchanged.
