v1.0.20-rc1 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.19

**Windows: live IN meter (#364)**

- modem73 on Windows now reports its own capture level on the control port (`audio_in_db`), the same field the Mac/Linux build already sends. It is read from the sound stream modem73 already has open, so there is no second capture stream (that glitched MFSK before).
- The IN meter and `/status` now move while the station only listens, instead of reading -80 dB / "low" until a line decodes.
- If nothing measures the input live (an older modem73, or capture down), IN now shows "—" instead of "low", on every platform.

**Desktop app: MAIL GW key (#362)**

- In the modem73 layout, a small dashed key sits to the right of the ACTIVITY graph and explains the four MAIL GW states: Not asked yet (grey), Asking (magenta), Gateway ready (green), No gateway (gold).
- Only shown in Radio+ with a mail gateway set. Hover it for the full meanings; on a wide window (about 1600 px or more) the short meanings show in the key too.
- The graph keeps its cell size and shows a little less history; nothing overlaps at the smallest window (820 × 520).

**VOX setup and help (#365)**

- `wcr setup`, the app's setup (Audio cable (VOX)), `wcr help radio` and the website VOX guide now say: squelch 1 (not 0) and a mid VOX level (4 worked on a VR-N76). At squelch 0 the radio hears noise all the time and its VOX may not key.
- The trade-off is stated plainly: with the squelch on, wcr only hears signals strong enough to open it, so the weakest lines are lost, a line's start can be clipped, and the busy check only sees the channel as busy while the squelch is open. Wired PTT or a Bluetooth radio avoids this.
- Lead tone level checked in modem73's code: the VOX lead is a full sine at 0.8 of full scale, about 2 dB louder (RMS) than the RDM-600S data, and the TX level scales both the same. If the radio keys on the data, it keys on the lead.

No change to the Live Chat radio code; the radio signal format is unchanged, so rc1 talks to v1.0.19 and v1.0.18.
