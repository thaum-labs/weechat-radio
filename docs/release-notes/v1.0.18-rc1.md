v1.0.18-rc1 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.17

**Range test mode (#325)**
- `/rangetest CALL` sends CALL a short private probe on the radio every 30 s. `/rangetest CALL 60` picks another gap (15 to 600 s). Probes are never retried, so each one shows whether that single try got through.
- CALL needs no update. Its normal receipt already carries the SNR it heard you at.
- Each probe is logged with your GPS position (set `[gps]` in setup) as `both`, `heard_them` (you decoded CALL but no receipt came back) or `none`, plus the SNR at both ends. The log is `range-test-CALL-date.csv`, with a `.kml` for Google Earth, in the WeeChat Radio folder on your Desktop (or the files folder on a Pi).
- A line in the chat after each probe says how it went. `/rangetest off` stops the test and `/rangetest` shows how it is going.
- New website page https://weechatradio.com/guides/range.html: drop one or more CSV files on it to see the coverage area (10° slices around the far station), route detail and every probe on a satellite or street map. The file stays in your browser.
