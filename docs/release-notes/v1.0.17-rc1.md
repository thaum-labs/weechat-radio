v1.0.17-rc1 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.16

**Desktop app: direct messages notify you and get their own chats (#303)**
- A direct message to your callsign used to land in a hidden "#yourcall" channel, so it only showed in **on air**. It now opens a direct chat with the station that sent it.
- New **direct** row under the channel picker: every station you have a direct chat with, newest first, with "N new" counts. Type a callsign and press **open** to start one; **close chat** takes it off the list.
- Every incoming direct message pops a system notification (macOS Notification Centre, Windows toast, Linux desktop notification), unless that chat is already open in the focused window.
- The **live chat** link in the top bar shows the unread count, like **email**.
- The list of direct chats is kept across restarts. The lines are not: the station does not replay direct history (same as the Pi web app).
- The new-mail notification uses the same notification path.

**/report sends on Enter (#304)**
- Picking `/report` or pressing Enter on it now sends straight away, like `/wx`.
- In a direct chat, a bare `/report` asks that station for a signal report; the answer arrives in the same direct chat.
- In a channel, a bare `/report` shows the usage line. `/report CALL` and `/report auto on|off` work as before.
