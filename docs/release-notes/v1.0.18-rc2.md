v1.0.18-rc2 is a release candidate. Get it with `wcr update --rc`.

## What changed since v1.0.18-rc1

**GPS satellites and traffic light (#329)**
- The GPS line in the desktop app's station panel shows how many satellites the receiver sees while it waits for a fix (`waiting for a fix, 5 satellites seen`), and how many it uses once it has one (`fix IO81UF12, 8 satellites`).
- A coloured dot shows red when no satellites are seen or the GPS is not answering, amber when satellites are seen but there is no fix yet, and green once it has a fix. At green, `/rangetest` logs your position.

**Range test map (website)**
- https://weechatradio.com/guides/range.html has a replay button that plays the drive back at 120x, 500x or 2000x real time, building up the coverage as it goes.
