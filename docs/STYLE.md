# Documentation style

Each guide is one task.

1. Start with **What you need**.
2. Give **numbered steps**. Use copy-paste commands. One action per step.
3. End with **How you know it worked**.
4. Plain English. If you must use a radio word, add a one-line gloss in parentheses.
5. Short pages. No background essays.
6. Show the command, then what you should see.

Do not write "simply" or "just". Do not assume the reader has used IRC or Linux before.
