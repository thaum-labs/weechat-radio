# Try it with two computers

Install on both computers (`wcr gui`). In setup, choose any radio with a plain audio cable (VOX) and preset `hf-poor`. If the radios only show channel numbers, type `446.006` and put both radios on the same channel.

Set MODE to `radio` on both computers so the words travel as sound.

Keep each radio next to its own computer, about an arm's length apart. Turn on the setting that transmits when the radio hears a sound (often called VOX). Set the computer volume about halfway. The radio light should come on when the computer makes a sound, and stay off when the room is quiet.

Type `hi` and press Enter. Wait. A short line on `hf-poor` can take half a minute. You should hear a tone and see the radio light. The other computer shows the words, and yours shows `[ok]`.

When that works both ways, set both computers to `vhf-fm` and send `hi` once more. If the other computer stays quiet, go back to `hf-poor`.

No cable: rest the radio microphone on the computer speaker, and the radio speaker on the computer microphone. No radio at all: point each computer's speaker at the other computer's microphone, a short gap apart. Both still use `hf-poor` and MODE `radio`.

If a line appears before you hear anything, it went over the internet. MODE `radio` keeps the test on the sound path.
