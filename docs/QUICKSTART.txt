WeeChat Radio — printable quick start
=====================================
With pictures: https://weechatradio.com/guides/start.html

1. Install
   Linux/mac:  curl -fsSL https://weechatradio.com/install.sh | sh
   Windows:    irm https://weechatradio.com/install.ps1 | iex

2. wcr setup
   Enter callsign, grid, and radio path.

3. wcr tui
   Type in #bulletin. Enter sends.

Marks: [..] waiting  [tx] sent  [rl] heard again  [gw] gateway took it
       [ok] delivered (#bulletin stops here)  [all] closed group
       [xN] times keyed ([x4] is the last copy)  [no] after two more waits
       Desktop app: the key button lists these. Radio lines show their SNR (/snr off).

Signal report: /report CALL   (answered automatically, /report auto off)
Weather:       /wx  or  /wx CALL   (your grid, needs internet)

Update: wcr update. Linux and macOS restart a service. A station you
started by hand keeps the old code until you start it again. Windows
too, including a service.

Beacons count down on the status bar (after exchange, pending, busy).
First three about a minute apart, then every 5 minutes.
rf.startup_hold_s (120) holds your first lines until another station is heard (not on VOX).

If the internet dies, keep using the radio. Status bar: "Internet down, radio only".

Calling frequencies (verify your band plan):
  UK/EU 2m   144.950 FM  vhf-fm
  US    2m   145.010 FM  vhf-fm
  UK/EU 40m    7.045 USB hf-poor
  WW    20m   14.070 USB hf-poor
  UK/EU 70cm 433.625 FM  vhf-fm
  Full list (160m–23cm, CB, PMR446, MURS, FRS): wcr help calling

Full guides: wcr help
