WeeChat Radio — printable quick start
=====================================
With pictures: https://weechatradio.com/guides/start.html

1. Install
   Linux/mac:  curl -fsSL https://weechatradio.com/install.sh | sh
   Windows:    irm https://weechatradio.com/install.ps1 | iex

2. wcr setup
   Enter callsign, grid, and radio path.

3. wcr tui
   Type in #bulletin. Enter sends.

Ticks:  · queued   ✓ sent   ✓✓ delivered   ✓✓✓ all group members

If the internet dies, keep using the radio. Status bar: "Internet down, radio only".

Calling frequencies (verify your band plan):
  UK/EU 2m  144.950 FM  vhf-fm
  US    2m  145.530 FM  vhf-fm
  UK/EU 40m   7.045 USB hf-poor
  US    40m   7.090 USB hf-poor

Full guides: wcr help
