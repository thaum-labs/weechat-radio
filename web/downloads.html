weechat-radio:$ downloads

      
Copy one command. No account. Leave the window open until it finishes — on Windows that is several minutes. Then run the 5-minute start.

      
linux / macos

      
curl -fsSL https://weechatradio.com/install.sh | sh

      
On Linux the installer may ask for your password and then sit while apt or dnf installs WeeChat. Leave that window open.

      
windows (powershell)

      
Click Start, type PowerShell, and open Windows PowerShell. No administrator needed: it installs for your user only. Paste:

      
irm https://weechatradio.com/install.ps1 | iex

      
Leave that window open. After the program downloads, WeeChat installs through Cygwin. The window prints waiting for WeeChat... and can sit for several minutes, sometimes toward 20. It is finished when it prints the next step. Open a new PowerShell window before wcr setup.

      
Release zips: GitHub Releases.

      
On Windows, the installer puts a WeeChat Radio shortcut on the Start menu and desktop. Open that — it starts the station and chat.

      
On Mac and Linux the program is wcr in ~/.local/bin. Open a new terminal, then run setup first, then the window:

      
wcr setup
wcr gui

      
If the shell says wcr: command not found, run export PATH="$HOME/.local/bin:$PATH" and add that line to your shell profile.

      
WeeChat (the separate IRC client) is optional. See the WeeChat guide if you want that client later.
