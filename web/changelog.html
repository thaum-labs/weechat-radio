weechat-radio:$ changelog

      
Numbers are the app. Run wcr update for those. The website has no version; it just changes when we publish it.

      

        

          
v0.1.52

          
Sun, 20 Sep 2026

        

        
Hearing our own ACK no longer paints [rl] over [ok]. An ACK addressed to us is not put back on the air. WeeChat and the TUI now use [ok] / [rl] so delivered and relayed are not the same mark.

      

      

        

          
v0.1.51

          
Sun, 20 Sep 2026

        

        
Radio stations still post map metadata when a telemetry URL is set; chat stays off the hub. In internet-radio the LAN mesh is a gap-fill like the hub, not an always-on second path.

      

      

        

          
v0.1.50

          
Sun, 20 Sep 2026

        

        
Hearing our own frame (speaker echo or a relay) no longer turns [ok] back into [rl]. A low-SNR ACK no longer steps the modem down; retries still go slower only when a line is actually missing.

      

      

        

          
v0.1.49

          
Sun, 20 Sep 2026

        

        
VOX stations no longer send automatic “I’m here” beacons; that 1400 ms tone was walking on inbound frames. The Windows IN meter falls back to empty after a quiet stretch instead of sitting on the last decode.

      

      

        

          
v0.1.48

          
Sun, 20 Sep 2026

        

        
A short group chat line that fits one modem frame is sent as one shot. vox-safe used to split those into three fragments, so chat stayed empty unless two arrived.

      

      

        

          
v0.1.47

          
Sun, 20 Sep 2026

        

        
Windows meters no longer tap the capture endpoint; that peak-meter Activate was breaking MFSK CRC. Slow presets (vox-safe, hf-deep, hf-poor, hf-weak) use a -50 dB CSMA threshold so the modem does not key over a quiet inbound frame.

      

      

        

          
v0.1.46

          
Sun, 20 Sep 2026

        

        
Windows IN/OUT meters read WASAPI endpoint peaks instead of opening a second capture. That second stream made modem73 reconnect in a loop and report no audio. A short audio-unhealthy blip no longer wipes the bars.

      

      

        

          
v0.1.45

          
Sat, 19 Sep 2026

        

        
Keep IN/OUT meters alive when modem73 reports a negative frame count. Drop the stuck “no modem” label after a later attach. Do not treat control events as command replies. Restart if modem73 exits. Bind chat and status before opening the store so the Mac GUI is not stuck on station starting.

vox-safe and hf-deep pass MFSK-32R as --mfsk-mode so modem73 stays up. A child that already exited is dropped instead of reused, so the next start can try again.

hub ce4a108

          
Thu, 17 Sep 2026

        

        
Weak-signal delivery is on the public hub.

- Protocol version 2 on radio and internet (version 1 still decoded)
- Smaller packets: compressed chat, shorter headers, unsigned on slow HF
- Unacked messages retry (default 3). Each retry uses a slower waveform
- New preset hf-deep (MFSK-32R). hf-poor / hf-weak use short RDM frames
- Emergency (!!) sent twice. Group HF chat split so any 2 of 3 pieces rebuild
- Hub stitches pieces heard by different gateways
- Status bar shows TX (waveform) and RETRY

Operator guide: https://weechatradio.com/docs/weak.html
Wire protocol: https://weechatradio.com/docs/protocol.html

Every station talking on radio with this hub should run this build.
