weechat-radio:$ cross-frequency chat

      
A station talks on one dial at a time. Same-frequency chat is radio. Different-frequency chat uses a gateway and the hub. The program never changes your radio frequency by itself.


      
Same frequency

      
Both stations set the same calling spot (for example UK 2m 144.950). No internet is required. Nearby stations hear you on the air. Others on that frequency can store-and-forward the message (TTL / hops left, default 3).

      

      
Different frequencies

      
2m cannot hear 40m. A station in internet-radio mode is a gateway (it has a radio and a hub link). The hub copies a message from the gateway that heard it to the gateway that has recently heard the destination — or that is the destination.

      

      
Radio-plus (you stay offline)

      
radio-plus never uploads. A nearby gateway that hears you on RF may forward your traffic to the hub, then to internet stations or another band.

      

      
What a gateway will and will not put on the air

      
      
    
        
  • RF → internet: the message must allow internet (INET_OK). radio mode never forwards to the hub.
    • 
        
  • Internet → RF: [gateway] rf_egress = true in wcr.toml. Guest names starting with ~ stay off RF unless third_party = "allow".
    • 
        
  • Same LAN: nodes on your local network can pass frames without the public hub. The same gateway rules still apply.
    • 
      

      
[gateway]
rf_egress = true          # put internet traffic on the air
third_party = "deny"      # guest (~nick) traffic on RF


      

        
You set the dial

        
FREQ in the GUI and /radio qsy are operator actions. The hub never retunes a radio. Pick spots from calling frequencies and check your band plan before you transmit.

      


      
How stations learn the band

      
Beacons are B|<mode>|<khz>, for example B|internet-radio|144950. A frame heard on RF is tagged with the receiving station’s own dial. Hub sessions carry freq_khz. The live map has a BANDS panel; nicklists show [2m], [40m], [inet].

How you know it worked

        
Nicklist tags match the bands: [2m] G4ABC, [40m] M7TJF, [inet] ~ALICE. The map ticker reads like G4ABC 2m TX -> #net -> 40m, inet. Your status bar shows your own frequency and band.
