weechat-radio:$ one group across PMR, CB, 2m, and internet

      
One closed group, #field (/join #field). A PMR446 handheld, a CB set, a licensed 2m radio, and a laptop with no radio all read the same thread.


      
    
        
  1. Each person stays on one dial. PMR, CB, and 2m cannot hear each other on the air.
    2. 
        
  2. A gateway on that dial (internet-radio) carries radio-plus lines to the hub.
    3. 
        
  3. The hub uses TLS (wss://hub.weechatradio.com/ws) and hands the line to the gateway on the other dial.
    4. 
      


      

        
Watch the #field thread cross the bands

        
Each column is one dial. The three radio columns never connect to each other — every line goes up to the hub and back down. Tap a line to replay its path.


        

        
A gateway keys a hub line onto its dial only when rf_egress = true and the destination was heard on that dial in the last 10 minutes. Guest names (~) also need third_party = "allow" (default is deny).

What the app does not do

        
    
          
  • PMR, CB, and 2m cannot hear each other on RF — only gateway + hub + gateway.
    • 
          
  • The program never retunes your radio across bands. Pick spots from the calling list and obey your band plan.
    • 
          
  • radio-plus never opens the hub from your PC; a gateway uploads when it hears you.
    •
