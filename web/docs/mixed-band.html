★ Featured guide

      
weechat-radio:$ one group across PMR, CB, 2m, and internet

      
Everyone joins the same closed group #field (/join #field). PMR446 and CB handhelds, a 2m mobile, and a laptop with no radio can read the same thread. Each band keeps its own dial; cross-band chat always passes through an internet-radio gateway on that band and the hub.


      
    
        
  • RF — modem on the dial you set (not TLS)
    • 
        
  • Hub — wss://hub.weechatradio.com/ws (TLS)
    • 
        
  • Gateway — internet-radio on one dial
    • 
        
  • Radio-plus — RF out; gateway may upload
    • 
        
  • Internet — hub only, no RF
    • 
      


      

        
Who is in #field

        
Settings match today’s setup wizard and /radio commands. Three operators run gateways (one dial each); everyone else stays on radio-plus or internet.

What the app does not do

        
    
          
  • PMR, CB, and 2m cannot hear each other on RF — only gateway + hub + gateway.
    • 
          
  • The program never retunes your radio across bands. Pick spots from the calling list and obey your band plan.
    • 
          
  • radio-plus never opens the hub from your PC; a gateway uploads when it hears you.
    •
