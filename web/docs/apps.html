Ease of use, and when to pick each

      
Ease of use means getting from download to your first message, then using the app day to day.

      
    
        
  • WeeChat Radio: easyOne install command, a seven-step setup, then a chat window. No radio needed to start. Early software, so expect changes. Pick it for live group chat over radio, internet or both, with email beside it.
    • 
        
  • Winlink Express: moderateThe standard for ham email and emergency forms, with a big gateway network. Many menus, a separate VARA or ARDOP install, and Windows only. Pick it when your group or served agency uses Winlink.
    • 
        
  • Pat: moderateWinlink in a browser window, on any computer. Setup means editing a config file and installing a modem yourself. Pick it for Winlink on Linux, macOS or a Raspberry Pi.
    • 
        
  • JS8Call: moderateFamiliar if you know FT8, and it gets through very weak HF paths. Messages are slow, and relays and inboxes use typed commands. Pick it for keyboard chat when the band is barely open.
    • 
        
  • VarAC: moderateA friendly chat screen, but it needs VARA set up first and runs on Windows only. Pick it for fast one-to-one HF chat with VARA users.
    • 
        
  • Fldigi + FLmsg: hardDozens of modes, a waterfall to tune by hand, and lots of settings. Very flexible once learned. Pick it for emergency forms (NBEMS) and classic digital modes.
    • 
        
  • FreeDATA: moderateA modern window and open source, but still in development and needs rig and audio setup. Pick it for open source HF messages and file transfer.
    • 
        
  • Meshtastic: easyPair a small LoRa node with your phone and chat. It is not a ham mode and covers kilometres, not continents. Pick it for local text when there is no phone signal.
    •
