weechat-radio:$ HF rig with CAT

      
CAT means the computer can talk to the radio over USB: change frequency and press the transmit button. About five minutes after Hamlib is installed.


      

      

        
What you need

        
    
          
  • An HF transceiver with USB CAT (IC-7300, FT-891, Xiegu, and most modern rigs)
    • 
          
  • Hamlib so rigctld is on your PATH (a command the computer can find)
    • 
        

      


      
Steps

      
    
        
  1. 
          
    Plug the radio USB into the computer. Leave the radio in USB, 2400 Hz filter if you have one.
    
        
    2. 
        
  2. 
          
    Find your Hamlib model number:
    
          
    rigctl -l
    
          
    On Windows: rigctl.exe -l.
    
        
    3. 
        
  3. 
          
    Start CAT. Replace MODEL, COM port, and baud with yours:
    
          
    rigctld -m MODEL -r COM3 -s 19200
    
        
    4. 
        
  4. 
          
    Run wcr setup and choose HF rig with CAT. Keep the default 127.0.0.1:4532.
    
        
    5. 
        
  5. 
          
    Pick a preset: hf-good on a clear band, hf-poor for NVIS (nearby skywave), hf-weak when signals are faint, hf-deep as a last-resort MFSK backup. Retries automatically step the modem down if ACKs do not come back.
    
        
    6. 
        
  6. 
          
    To change frequency, you type it. It never happens automatically:
    
          
    /radio qsy 7.045
    
        
    7. 
      


      

        
How you know it worked

        
The status bar shows the frequency the radio reports. A decoded frame shows SNR. If CAT fails, run /radio ptt vox and use the VOX path until CAT is sorted.

      


      
Path is fading? Weak signals. Other paths: handheld + Digirig · VOX cable. Frequencies: calling.
