weechat-radio:$ WeeChat

      
WeeChat is a separate chat program. The built-in window (wcr tui) is enough for most people. Use this page if you want WeeChat instead.


      

      

        
What you need

        
    
          
  • wcr node or wcr tui already running on this computer
    • 
          
  • WeeChat with the Python plugin (the official installer adds this)
    • 
        

      


      
Easy way

      
The official installer does this for you.

      
wcr node
wcr weechat

      
To rewrite the server and script later:

      
wcr weechat --configure


      
Manual way

      
Only if you installed WeeChat yourself.

      
    
        
  1. 
          
    Copy radio.py into WeeChat’s Python folder:
    
          
      
            
    • Linux and macOS: ~/.weechat/python/
      • 
            
    • Windows (WSL): same path inside WSL
      • 
          
    
        
    2. 
        
  2. 
          
    In WeeChat, paste these lines one at a time:
    
          
    /server add radio 127.0.0.1/6667 -autoconnect
/set irc.server.radio.tls off
/set irc.server.radio.capabilities "message-tags,echo-message,server-time,msgid"
/connect radio
/script load radio.py
    
        
    3. 
        
  3. 
          
    You land in #bulletin. Chat as usual. /radio help lists node commands.
    
        
    4. 
        
  4. 
          
    The script defaults to theme tron (indigo / orange, same as this site). Turn it off with:
    
          
    /set plugins.var.python.radio.theme plain
    
        
    5. 
      


      

        
How you know it worked

        
The radio bar at the bottom of WeeChat shows your mode and SNR, like INTERNET-RADIO │ IDLE │ VHF-FM │ SNR 12. Sending a message adds ticks on the line (✓ then ✓✓).

      


      
Prefer the built-in window? 5-minute start uses wcr tui.
