guides › Install on your computer › Linux setup

      
weechat-radio:$ Linux setup

      
Same install command as macOS. Then run setup, then the window.


      

        
What you need

        
    
            
  • 
              
              A current Linux
            
    • 
            
  • 
              
              A terminal
            
    • 
        

      


      

        
Steps

        
    
          
  1. 
            Install wcr
            
    Install:
    
            
    curl -fsSL https://weechatradio.com/install.sh | sh
    
            
    Before WeeChat is installed, the installer says it will use apt or dnf and that sudo may ask for your password. If ~/.local/bin is not on PATH, it adds that directory to your bash, zsh, or fish profile and prints the line to run in this terminal.
    
          
    2. 
          
  2. 
            Join the serial group
            
    If you will plug in a USB radio cable, add your user to the serial group, then log out and back in:
    
            
    sudo usermod -aG dialout $USER
    
          
    3. 
          
  3. 
            Run setup
            
    Run setup first. It asks for your callsign, grid, and whether you have a radio:
    
            
    wcr setup
    
          
    4. 
          
  4. 
            Open the chat window
            
    Then open the chat window:
    
            
    wcr gui
    
          
    5. 
          
  5. 
            Run in the background
            
    Background service:
    
            
    wcr service install
    
            
    wcr update replaces the binary and restarts this service. A station you started by hand keeps the old code until you stop it and start it again.
    
          
    6. 
          
  6. 
            Open WeeChat
            
    The installer also sets up WeeChat. After wcr node, run wcr weechat. To rewrite the server and script: wcr weechat --configure.
    
          
    7. 
        

      


      

        
How you know it worked

        
wcr gui shows your callsign. A message in #bulletin gets a [tx]. If you installed the service, wcr service status prints active. Email is the other tab in that window. Email.
