guides / Windows

      
weechat-radio:$ Windows

      
Install on Windows 10 or 11, then open the chat window.


      

        
What you need

        
    
          
  • Windows 10 or 11
    • 
          
  • PowerShell, a normal window (Start → type PowerShell → open it). The install is for your user only, so it does not need administrator.
    • 
        

      


      
Steps

      
    
        
  1. 
          
    In that PowerShell window, paste this and press Enter:
    
          
    irm https://weechatradio.com/install.ps1 | iex
    
          
    Leave the window open. The installer downloads the program, then WeeChat through Cygwin. It prints waiting for WeeChat... and can sit for several minutes, sometimes toward 20. It is finished when it prints the next step. That adds WeeChat Radio to your user PATH. This window does not see it yet, so open a new PowerShell window before wcr setup. Or download a zip from GitHub Releases and put wcr.exe somewhere on your PATH.
    
        
    2. 
        
  2. 
          
    Run setup first. It asks for your callsign, grid, and whether you have a radio:
    
          
    wcr setup
    
        
    3. 
        
  3. 
          
    Then open the chat window:
    
          
    wcr gui
    
        
    4. 
        
  4. 
          
    To keep the node running after you close the window, open PowerShell as Administrator and run:
    
          
    wcr service install
    
          
    wcr update replaces the binary. Stop the station and start it again, including this service. A station you started by hand keeps the old code until you do.
    
        
    5. 
        
  5. 
          
    The installer also sets up WeeChat. After wcr node, run wcr weechat. To rewrite the server and script: wcr weechat --configure. Other IRC programs can connect to 127.0.0.1:6667.
    
        
    6. 
      


      

        
How you know it worked

        
wcr gui shows your callsign in the status bar. A message in #bulletin gets a [tx]. The email tab is next to live chat. How email leaves the station.

      


      
Back to the 5-minute start, add a radio, or see troubleshooting if the install stops, the clock is off, or the window never appears.
