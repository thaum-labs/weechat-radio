guides / Windows

      
weechat-radio:$ Windows

      
Install on Windows 10 or 11, then open the chat window.


      

        
What you need

        
    
          
  • Windows 10 or 11
    • 
          
  • PowerShell (comes with Windows: Start → type PowerShell → Enter)
    • 
        

      


      
Steps

      
    
        
  1. 
          
    In PowerShell, paste this and press Enter:
    
          
    irm https://weechatradio.com/install.ps1 | iex
    
          
    Or download a zip from GitHub Releases and put wcr.exe somewhere on your PATH.
    
        
    2. 
        
  2. 
          
    Answer the questions:
    
          
    wcr setup
    
        
    3. 
        
  3. 
          
    Start chatting:
    
          
    wcr tui
    
        
    4. 
        
  4. 
          
    To keep the node running after you close the window, open PowerShell as Administrator and run:
    
          
    wcr service install
    
        
    5. 
        
  5. 
          
    The installer also sets up WeeChat. After wcr node, run wcr weechat. To rewrite the server and script: wcr weechat --configure. Other IRC programs can connect to 127.0.0.1:6667.
    
        
    6. 
      


      

        
How you know it worked

        
wcr tui shows your callsign in the status bar. A message in #bulletin gets a ✓.
