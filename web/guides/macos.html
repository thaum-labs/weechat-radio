guides / macOS

      
weechat-radio:$ macOS

      
Same install command as Linux. Then run setup, then the window.


      

        
What you need

        
    
            
  • 
              
              A Mac
            
    • 
            
  • 
              
              Terminal
              Command + Space, type Terminal, press Enter.
            
    • 
        

      


      

        
Steps

        
    
          
  1. 
            Install wcr
            
    Install:
    
            
    curl -fsSL https://weechatradio.com/install.sh | sh
    
            
    This downloads wcr. It does not run brew install weechat. Homebrew has no tap for this project yet, and on older macOS it would compile WeeChat from source.
    
          
    2. 
          
  2. 
            Run the export line
            
    The installer adds ~/.local/bin to your bash, zsh, or fish profile when it is not already on PATH. This terminal does not see that yet. Run the export line it printed, then wcr setup.
    
          
    3. 
          
  3. 
            Run setup
            
    Run setup first. It asks for your callsign, grid, and whether you have a radio:
    
            
    wcr setup
    
            
    The installer puts modem73 (the radio sound box) next to wcr, same as Windows and Linux. After setup, a test line in radio mode should play tones on the speakers.
    
          
    4. 
          
  4. 
            Open the chat window
            
    Then open the chat window:
    
            
    wcr gui
    
          
    5. 
          
  5. 
            Run in the background
            
    To run in the background:
    
            
    wcr service install
    
            
    wcr update replaces the binary and restarts this service. A station you started by hand keeps the old code until you stop it and start it again.
    
          
    6. 
          
  6. 
            Add WeeChat later
            
    WeeChat is optional. To add it later, see the WeeChat guide.
    
          
    7. 
        

      


      

        
How you know it worked

        
The status bar shows your callsign and mode. #bulletin accepts a test message. The email tab sits next to live chat. Email.
