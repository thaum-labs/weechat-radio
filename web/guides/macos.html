guides / macOS

      
weechat-radio:$ macOS

      
Install on a Mac, then open the chat window.


      

        
What you need

        
    
          
  • A Mac
    • 
          
  • Terminal (Command + Space, type Terminal, press Enter)
    • 
          
  • Homebrew, or use the one-line installer below
    • 
        

      


      
Steps

      
    
        
  1. 
          
    Install. Homebrew:
    
          
    brew tap thaum-labs/tap
brew install wcr
    
          
    Or the website installer:
    
          
    curl -fsSL https://weechatradio.com/install.sh | sh
    
        
    2. 
        
  2. 
          
    Answer the questions:
    
          
    wcr setup
    
          
    Windows and Linux already bundle modem73 (the radio sound box). On a Mac, install modem73 if you want radio.
    
        
    3. 
        
  3. 
          
    Start chatting:
    
          
    wcr tui
    
        
    4. 
        
  4. 
          
    To run in the background:
    
          
    wcr service install
    
        
    5. 
        
  5. 
          
    The installer also sets up WeeChat. After wcr node, run wcr weechat. To rewrite the server and script: wcr weechat --configure.
    
        
    6. 
      


      

        
How you know it worked

        
The status bar shows your callsign and mode. #bulletin accepts a test message.
