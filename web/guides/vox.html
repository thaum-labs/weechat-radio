weechat-radio:$ Any radio with VOX

      
VOX means the radio transmits when it hears sound. A plain audio cable is enough. About five minutes.


      

        
What you need

        

          
    
            
  • 
              
              Any radio that can key on VOX (voice-operated transmit)
            
    • 
            
  • 
              
              A 3.5 mm audio cable
              From the computer sound card to the radio mic/speaker.
            
    • 
            
  • 
              
              Volume set
              So the radio keys on data tones, not on room noise.
            
    • 
          

        
        

      


      

        
Steps

        
    
          
  1. 
            Connect the cables
            
    Connect computer headphone-out to radio mic-in, and radio speaker-out to computer mic-in.
    
          
    2. 
          
  2. 
            Turn on VOX
            
    On the radio, turn VOX on. Start with a medium VOX delay.
    
          
    3. 
          
  3. 
            Run setup
            
    Run wcr setup and choose Any radio with a plain audio cable (VOX). This selects the vox-safe preset: RDM-600S (robust over a speaker and mic) and a 900 ms lead so the radio is fully keyed before data starts.
    
          
    4. 
          
  4. 
            Send a test
            
    Start wcr tui. Send a short test to #bulletin. Tell the app the frequency on the dial: /radio freq 144.950.
    
          
    5. 
          
  5. 
            Fix a clipped start
            
    Keep radio VOX hang on the long side. If the other station still hears a clipped start, raise modem.vox_lead_ms in wcr.toml (try 1200).
    
          
    6. 
        

      


      

        
How you know it worked

        
The radio’s TX LED lights for each message. Delivery ticks still work; they take a little longer because of VOX delay.
