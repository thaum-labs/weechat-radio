guides / 5-minute start

      
weechat-radio:$ 5-minute start

      
You will install a small program called wcr, give it a name, and send a chat line. You do not need a radio for this.


      

      

        
What you need

        
    
          
  • This computer (Windows, Mac, or Linux)
    • 
          
  • A ham radio callsign, or a guest name starting with ~ (example: ~alice)
    • 
          
  • A grid square if you want to show up on the map (example: IO91wm). Search the web for “maidenhead grid square map” and click where you live.
    • 
        

      


      
Steps

      
    
        
  1. 
          
    Open a command window.
    
          
      
            
    • Windows: click Start, type PowerShell, press Enter.
      • 
            
    • Mac: press Command + Space, type Terminal, press Enter.
      • 
            
    • Linux: open Terminal from the applications menu.
      • 
          
    
        
    2. 
        
  2. 
          
    Paste the install line, then press Enter.
    
          
    Linux / Mac
    
          
    curl -fsSL https://weechatradio.com/install.sh | sh
    
          
    Windows (PowerShell)
    
          
    irm https://weechatradio.com/install.ps1 | iex
    
        
    3. 
        
  3. 
          
    Run the setup wizard. It asks for your callsign, grid, and whether you have a radio.
    
          
    wcr setup
    
          
    If you have no radio, choose internet-only. You can add a radio later.
    
        
    4. 
        
  4. 
          
    Start the chat window.
    
          
    wcr gui
    
          
    Terminal instead: wcr tui. Want WeeChat? See the WeeChat guide — the Mac installer does not install that client.
    
        
    5. 
        
  5. 
          
    You land in a room called #bulletin. Type a short hello and press Enter.
    
        
    6. 
      


      

        
How you know it worked

        
The bar at the bottom of the window shows your callsign.

        
After you send, a mark appears on the line:

        
    
          
  • [..] waiting to go out
    • 
          
  • [tx] sent
    • 
          
  • [rl] relayed
    • 
          
  • [ok] delivered
    • 
          
  • [all] every station in a group got it
    • 
        

      


      
Words you will see

      

        

          
            
WordMeaning

          
          
            
wcrThe WeeChat Radio program

            
callsignYour ham ID, or a guest name like ~alice

            
gridShort location code for the map

            
hubThe public internet meeting point

            
TUIThe built-in chat window (wcr tui)

          
        

      


      
The window uses the same indigo / orange look as this site. Change it later with /radio theme hacker or /radio theme terminal.
